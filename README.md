# SmartSpend

SmartSpend is an AI-powered personal finance and spending analytics
web application developed as an MCA final-year major project.

## Technology Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Recharts
- Framer Motion
- Lucide React

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- JWT

### Database
- PostgreSQL
- Supabase

### AI
- Groq API

### Machine Learning
- Python
- FastAPI
- Pandas
- NumPy
- Scikit-learn

## Project Structure

- `frontend` — React frontend
- `backend` — Spring Boot backend
- `ml-service` — Machine learning service
- `docs` — Project documentation
